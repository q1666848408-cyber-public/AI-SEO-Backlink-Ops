# Vendor Cross-Linking Strategy

## Goal

Establish reciprocal linking relationships with complementary AI tools and services.

## Target Categories

| Category | Examples |
|----------|----------|
| AI coding tools | Code editors, CLI tools |
| LLM clients | Desktop apps, browser extensions |
| Dev frameworks | LangChain, LlamaIndex ecosystem |

## Approach

1. Identify tools that integrate with our gateway
2. Reach out proposing mutual "integration" page links
3. Create dedicated integration documentation
4. List each other on respective "integrations" pages
