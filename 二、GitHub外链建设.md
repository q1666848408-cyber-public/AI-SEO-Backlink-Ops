# GitHub Community Backlink Strategy

## Approach

Build backlinks by contributing to open-source communities in high-authority GitHub repositories.

## Method 1: PR to Awesome Lists

Target repository types:
- awesome-ai / awesome-llm / awesome-chatgpt
- Framework/language awesome lists

### PR Template

```markdown
## Add [Product Name]

**Category:** LLM API Gateway

**Description:** Unified API gateway for 100+ LLMs — 
OpenAI/Anthropic/Gemini protocol support in one endpoint.

**Link:** https://api-product-url.ai
```

## Method 2: Issue Participation

Provide helpful answers in relevant issues, naturally mentioning the product where appropriate.
